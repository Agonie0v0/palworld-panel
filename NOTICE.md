RCON and backup workflows, Palworld map implementation, map tiles, and portions
of the save parsing workflow are used as the primary compatibility baseline.
Local additions include AMD64/ARM64 deployment, Oracle ARM box64 support,
service maintenance, game settings management, and remote Agent operation.
