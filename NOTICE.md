Palworld Panel

This project references and builds upon ideas and publicly available resources
from palworld-server-tool:

  Project: https://github.com/zaigie/palworld-server-tool
  Copyright 2024 zaigie
  License: Apache License, Version 2.0

The player and guild information architecture, responsive management patterns,
Palworld map approach, and portions of the save-management workflow were
developed with palworld-server-tool as the primary reference. Public map tiles
are loaded from that project on demand so the ARM deployment remains small.

The original project and its contributors are gratefully acknowledged. Nothing
in this repository should imply that their work was created by this project's
authors.
