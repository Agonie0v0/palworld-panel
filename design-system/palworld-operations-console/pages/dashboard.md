# Dashboard override

The dashboard is a live world-status surface, not a player lobby.

- Lead with the world pulse, followed by base shifts and Pal worker rows.
- When no players are online, say that the world is still running and continue showing base activity.
- When players are online, append a compact player roster below the worker rows.
- Keep host resources and backup automation in a narrow secondary rail.
- Prefer direct labels and exact values over charts unless a trend materially changes an operator's decision.
- At 920px, move the side rail below world activity. At 620px, reduce each worker row to portrait, identity, and current state.
