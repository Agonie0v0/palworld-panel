# Product

## Register

product

## Platform

web

## Users

Self-hosted Palworld server administrators who need to deploy and operate servers from desktop or mobile without repeatedly editing files over SSH. The primary workflow is routine server administration: checking health, managing players, adjusting settings, running commands, and protecting world data.

## Product Purpose

Provide one dependable panel for deploying and managing Palworld servers on AMD64 and ARM64 hosts. Success means an administrator can complete common and advanced operations from the Web UI while still understanding what will change on the server.

## Positioning

The familiar palworld-server-tool management experience, extended with one-click deployment, Oracle ARM support, and full remote Agent operations.

## Brand Personality

Practical, clear, dependable. The interface should feel like an operations tool: calm under pressure, explicit about consequences, and efficient for repeated use.

## Anti-references

Avoid marketing-page composition, decorative dashboards, oversized headings, hidden side effects, and controls that expose configuration without explaining how or when it takes effect.

## Design Principles

- Keep the current task visible and make the next required action explicit.
- Preview destructive or broad configuration changes before applying them.
- Prefer familiar administration controls and dense, scannable information.
- Preserve existing settings unless the administrator deliberately replaces them.
- Provide equivalent core workflows on desktop and mobile.

## Accessibility & Inclusion

Maintain keyboard-operable controls, readable contrast, clear validation messages, touch-friendly mobile actions, and layouts that remain usable with long translated labels.
